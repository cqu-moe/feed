# Mistral OCR 3 / 4.1 实测

2026-10-11。Worker 从私有 R2 取出同一份已归档 PDF，直接调用 Mistral，响应回存 R2。未使用本机浏览器或 Browser Run 采集、渲染或推理；本地渲染只用于逐页人工核对。

## 样片和控制变量

- 通知：2026级本科学生“绿色通道”补助发放名单公示，article `4ffc0415b5f4ba168a847f01`。
- PDF：342,150 bytes，8 页，均无文字层；每页原始图像 793×1122。第 1 页通知，第 2–8 页名单，287 行、5 列。
- SHA256：`8744b23b7670980e444426297669573a7800c5e44ba861219904a9dde61cbfd8`。
- 两模型均使用 pages=[0..7]、table_format=null、include_image_base64=false，无 annotations；每模型只真实请求一次。
- 精确模型 ID 与响应实际 model 一致，未用 latest 别名。保存完整 usage、请求参数、原始响应和派生文本；原 PDF 不变。

两次合计估算 **$0.048**。价格来自 [OCR 3 官方模型页](https://docs.mistral.ai/models/ocr-3-25-12)、[OCR 4.1 官方模型页](https://docs.mistral.ai/models/ocr-4-1) 与 [官方价格](https://docs.mistral.ai/inference/pricing)；这里是实际响应页数乘标准价，并非最终发票，不包含 Cloudflare 运行与存储。

两个模型第 2–8 页分别返回 40/42/42/42/44/46/31 行，学院、学号、金额、序号在两份结果中一致；57 行的姓名存在差异。模型间一致不代表全部字段均正确。35 行人工样本内的学院、学号、金额和序号均与原图一致。

## 复核方法和局限

先不看模型响应，从原 PDF 的第 2、5、8 页独立转录 37 行。看到差异后放大原页复核，修正第 4 行人工初抄错字，剔除第 257、286 行难以可靠判读的姓名，最终计 35 行。金标修订与理由保存在私有 visual-gold.json。

另从 57 个模型间差异中，在第 2、5、8 页选择 25 个可清楚判读的姓名重点复核。此集合刻意包含差异，存在选择偏差，**3/25 与 22/25 绝不是整体姓名准确率**；35 行也只是便利样本，不能外推为所有中文 PDF 的准确率。单次延迟不能当作性能基准。

4.1 改善了多处复杂人名，但仍有“圆→园”、姓氏“覃→董”等错误；低分辨率原图对两个模型都有影响。不按两个模型投票自动改名，也不让模型臆测姓名。本次发布保持 4.1 原始转录内容，界面明确提示对照原 PDF。

## 选型和接入

选 **OCR 4.1** 为自动任务默认模型。此文档比 OCR 3 多 $0.016，复核中改善明显；按每月 1000 页估算，多约 $2，适合当前小规模通知归档。OCR 3 保留为显式管理对照选项，不同时自动跑两个模型。

已有 4.1 结果直接复用发布，正文和表格按页可读，FTS5 能检索扫描件中的中文与学号，页面可跳回原 PDF 对应页。新正文 PDF 在存档后进入独立云 Workflow；去重、预算和原件保护见 [实现说明](pdf-ocr-design.md)。

私有对比数据与截图位于 `.private/ocr-comparison/`，不提交学生名单或凭据。云端 job：OCR 3 `409f07feda47ed9f00e793c8685a8e6c81430fa7`，OCR 4.1 `2ae6ea26e31a15f000fa1284f6aad18a89e19e73`。
