# Feed 接入阿里云百炼文档搜索知识库

**已确认的产品范围 · 2026-11-05。** [规格 #77](https://github.com/cqu-moe/feed/issues/77) 及其五个子任务记录验收条件。实现默认关闭百炼读写；[启用与回滚](../bailian-search-operations.md)单列真实环境验收。选型依据见[百炼与 Viking 能力对照](../research/2026-11-05-bailian-viking-capabilities.md)。

## 1. 读者会得到什么

沿用通知页一个搜索框。输入「补考」、文件号、通知原句，或「挂科以后还能怎么参加考试」，都向同一个百炼知识库发起关键词＋语义混合检索；由百炼重排，Feed 以**通知**而非片段为单位展示。标题下显示命中原文、出处（网页正文／正文 PDF／附件名）；能定位原页时可直接打开受保护的 PDF 阅读器。结果是“相关通知”，不显示虚构的全库命中总数、不承诺按字面查全，不因两字查询自动跑 D1 全文扫描。

- **筛选**：发布日期含起止日；日期未知的通知只参与无日期限制的检索。部门指发布站点，栏目指采集源，不推断落款。仅选一个部门／栏目即可搜索；两者同时选时须属于同一站点。同一通知在两个栏目实际收录时，两边均可查，全站只显示一篇。日期与当前阅读页展示的发布日期一致，不能以上传、采集或转发时间替代。
- **有词与无词分开**：有词按相关性；没输入词时，部门、栏目、日期由 D1 用结构化字段筛选，继续按时间分页浏览，不消耗百炼查询。原列表、阅读、订阅和 RSS 可独立运行。
- **读哪个版本就搜哪个版本**：只搜当前向读者开放的可读版本；新版归档尚未完成时保留上一可读版。一旦阅读已切到新版但新索引未就绪，暂不显示失效片段。归档历史可照常查阅，不混入默认搜索。新旧格式的已完成历史文章都纳入回填。

## 2. 数据和职责

| 组件 | 管什么 |
|---|---|
| R2 和现有归档／OCR 链路 | 保管原件、原始版本和逐页识别结果。仍然是可核对的原文；不把私有桶、快照、截图或限时阅读地址交给知识库爬取。 |
| Feed / D1 | 管文章身份、当前可读版本、真实栏目关系、发布日期和阅读权限。另记本次同步所需的远端文件、导入任务、目标版本及状态；不另建中文倒排或向量库。 |
| 百炼 | 一个私有「文档搜索」知识库，内置向量存储；显式选 `text-embedding-v4`，关键词＋向量双路召回，使用 `qwen3-rerank`。首版仅取片段；不调用答案生成、多轮改写或多库路由。模型和检索配置固定记录，升级时可重建。 |

**发送内容。** 每篇通知输出一份网页正文（含标题和可读表格），每个有文字的正文 PDF / 普通 PDF 另出一份带原件页号的 Markdown。仅 PDF 通知也保留通知标题和来源。网页“详见附件”等占位不当正文；避免把阅读视图中已拼入的 PDF 文字再作为网页正文重复发送。保留表头与对应行；普通附件与正文 PDF 指向同一原件时按原件身份去重。上传的是通知内容及少量检索字段，不含用户身份、订阅或会话。含名单的可读通知进入派生索引的范围同其他通知；不会把搜索开放成公共接口。

**PDF 的约定。** 有文字层优先直接提取；正文型扫描 PDF 沿用 Feed 原有 OCR、缓存、配额和人工复核机制，搜索不启动第二次付费识别。普通 PDF 使用可直接提取的文字及已有 OCR，普通扫描页没有现成文字就不自动付费。混合页沿用归档的识别规则；超出现有提取上限、损坏原件或正文识别失败单列原因，不把空文件算为全文可搜。[现有逐页提取](../../worker/pdf-text.mjs) · [正文及附件 OCR 边界](../pdf-ocr-design.md)

**来源定位。** 本地映射百炼文件 ID → 通知、阅读版本、原件槽位、原件／派生文本指纹。PDF Markdown 用 Feed 的真实页序分节，沿用已存页文本；根据返回的标题层级、命中原文与相应页内容核对，能唯一定位就以现有 `/reader/…?page=N` 阅读入口打开正确页。多页可显示范围；无法可靠定位只显示文件，不猜页。百炼对上传的 Markdown 返回的分页不能直接当原 PDF 页码；前端也不使用百炼返回的外链。[阅读器现有跳页](../../src/ocr-reading.tsx)

## 3. 百炼资源、写入和过滤

**资源。** 首期目标为北京地域、标准版、Feed 专用业务空间或与其他业务隔离的空间、专用文件类目、一个内置存储的文档搜索库、一个已发布且只绑定该库的知识检索服务。运行时通过 Worker 的 `fetch` 调 REST，不增加服务进程、模型 SDK 或自购数据库。API Key 放 Worker Secret；空间 ID、类目 ID、知识库 ID、检索服务 ID 和功能开关作为按环境配置。验证环境和生产不得指向同一可写索引；不自动升级旗舰版。

| 操作 | 指定的接口与处理 |
|---|---|
| 上传派生文件 | [申请租约](https://help.aliyun.com/zh/model-studio/rag-api-upload-lease) → 按租约指定头 PUT 到临时 OSS 地址 → [addFile](https://help.aliyun.com/zh/model-studio/rag-api-add-file) 注册到 Feed 类目，附稳定标签，保存文件 ID。不把百炼 Bearer 转发给 OSS。 |
| 追加索引 | [提交导入](https://help.aliyun.com/zh/model-studio/rag-api-submit-sync-job)固定使用 `sourceType=DATA_CENTER_FILE` 和明确、非空的 `docIds`；不省略范围，不对整个数据中心导入。按[任务状态](https://help.aliyun.com/zh/model-studio/rag-api-get-sync-job-status)检查每一文件的解析／索引结果，不能用上传成功、任务被接受或批任务结束替代逐文件成功。 |
| 发起用户查询 | 只用[知识检索服务](https://help.aliyun.com/zh/model-studio/knowledgesearch)：`POST /api/v1/indices/knowledge/search`，Worker 传已发布的 `agent_id`、`query`、单库 `kb_search_configs`。校验业务成功标记，读取 `data.nodes[].metadata.doc_id/content` 及来源。不要把另一个 Retrieve 接口的 JSON 或配置照搬到这一端点。 |
| 移除与清理 | 先停显旧映射，再[删除知识库文档和切片](https://help.aliyun.com/zh/model-studio/rag-api-delete-document)；不再被引用且确属 Feed 的数据中心副本再[删除文件](https://help.aliyun.com/zh/model-studio/rag-api-delete-file)。不影响 R2 原件及归档历史。 |

**过滤落地。** 使用索引时写入的确定性字段，不让模型从落款或正文推断发布日期和部门。部门与栏目优先用 `addFile.tags` 保存全部实际成员关系（同一文档不因转发而重复上传）；标签短且有类型前缀，查询端验证所给栏目属于所选站点。日期也使用可由 `addFile` 直接写入的标签，不假设能够给每个切片写自定义数值字段。将日期视为连续的日序号，每份已知日期的文件打上当天以及覆盖它的逐级区间标签。查询把起止日期分解成不重叠的区间，在同组 OR，与部门／栏目组 AND。这样单端日期也能在一次检索中表达，无需查询 D1 的最早／最晚日期；未知日期不打日期标签。超过文档标签限制时阻止上传，不截断栏目。一个必须通过的反例：目标通知在全库排名靠后，限制到其栏目及发布日期后仍可找到；若远端过滤无法满足这个行为，不打开搜索开关。

## 4. 增量同步、回填与故障恢复

触发点是**可读内容或筛选信息改变**，不是“刚发现 URL”或“发送了一封邮件”。接入当前阅读版本发布、OCR 同版本重建、原件／普通附件派生文字变化、标题或日期更正、实际栏目成员变动及不再可读。禁用一个采集源只表示停止采集，不自行解释为删除历史通知；以实际阅读资格和栏目关系为准。[可读版本发布](../../worker/archive-reconcile.mjs) · [OCR 更正](../../worker/archive-ocr.mjs) · [栏目关系](../../migrations/0006_sources.sql)

1. **登记。** 在读模型提交时持久登记需同步的目标；对其余入口同样登记，另用带游标的低频对账兜住旧档及遗漏。每个正文／附件按稳定槽位和内容、元数据、解析策略的指纹判断是否变化。最少的持久状态要能表达目标指纹、当前生效及待清理的远端 ID、导入任务、重试时间和错误；不复制一份可读正文到 D1。利用现有调度／维护入口限批执行，搜索失败不能回滚文章归档或拖死采集。
2. **执行。** 新内容优先，历史分小批。状态区分待传、已注册、导入中、已就绪、需处理、待删除。重试先按持久任务号／文件名和指纹核对，避免超时后重复注册、重复付费；同一文档并发更新时只有与当前目标一致的完成结果可以生效。远端遗留文件进入清理。如 429 或临时错误则退避；鉴权、配置和格式错误停止该项，给管理员可读原因。
3. **一致性。** 查询时按命中的远端文档 ID 批量回查 D1，确认它仍对应当前可读版本、当前附件和筛选范围，再向前端输出片段。新索引晚到允许暂时少结果，不允许一篇已修正的通知继续展示旧金额或旧名单。一次 OCR 修正、补索引或回填不会制造通知版本、RSS 条目或邮件。
4. **历史回填。** 盘点当前可读通知（含已完成旧格式）、正文 PDF、普通可提取附件、已有 OCR、按政策跳过的扫描附件及异常项。先列清单和费用估算，再复用同一条增量链路回填，不重抓源站，不清空归档。管理员能查看已就绪／待处理／失败／明确跳过的**通知数和文件数**，暂停和从断点恢复；正文必需文字缺失不能报整篇完成。用量记录包含请求数、限流、失败类别和待清理数量，不记用户原始搜索词或名单片段。

实现时要逐个核对两个容易漏掉的边界：[同版本 OCR 更新](../../worker/archive-ocr.mjs)会原地更新 `extraction_generation`，不能只看 revision ID；[来源关联与事件日期核正](../../worker/notifications.mjs)不是读模型的正文更新。即使正文指纹不变也要重算归属；日期仅在当前阅读展示的发布日期发生改变时才重写，某一次投递事件的日期核正不自动改写通知的发布日期。旧格式、历史补抓和仅呈现层发生变化的可读版本，不要求先存在可投递事件。

## 5. 查询、故障时的体验与费用

保留现有通知 URL、筛选和阅读入口；浏览继续用现有 `GET /api/articles`，有词时界面继续向同一个受保护列表端点提交 `q/site/source/from/to`；开启百炼读取后路由到新检索端点使用的同一个处理函数。显式 `GET /api/articles/search?q=…` 仅在百炼读取启用时可用。返回已核对的文章、一个或少量最佳命中及来源，不复用旧分页协议里的“文章总数”。先调用现有 Auth 的 `feed.access` 鉴权，后访问百炼；客户端不接触密钥、供应商文档 URL 或原始模型响应。关键词和自然语言均可输入，不额外提供会暗示字面查全的模式。

正式模式不在每次按键时调用：提交或明确应用筛选时才检索，抑制重复提交。初始建议双路各取 20 个候选，重排最多返回 20 个片段，再按通知去重，不承诺凑齐 20 篇。429／超时／百炼不可用与“确实无结果”分开显示，可按原筛选继续浏览；不悄悄退回 D1 的短词全文扫描。灰度回滚开关则可整站恢复原有产品行为。

标准版按 720 小时约 **¥21.60/月/库**，1 QPS、含最多 100 GB 平台存储，查询嵌入、入库嵌入与重排另计；重排按送入模型的候选片段计费，而非按最终展示的通知数。举例：每月 1,000 次，每次实际送排 40 段 × 平均 300 token，按官方 `qwen3-rerank` 示例价 ¥0.0005/千 token，仅重排约 **¥6**；基础费、入库和查询嵌入另算。样例不是账单预测。首发仅标准版；回填前给出按实际文件量的估算，支持独立停回填、停查询；停请求不会停止知识库基础费，弃用测试库应删除。[计费与示例](https://help.aliyun.com/zh/model-studio/billing-for-knowledge-base)

## 6. 实施顺序与放行条件

| 步骤 | 放行依据 |
|---|---|
| ① 本地与 CI | 在隔离工作树实现上传适配、过滤、状态同步与通知页；复用现有权限和 PDF 阅读组件。跑仓库 CI、浏览器回归，覆盖重复投递、旧任务晚到、更新／删除和 429。替身通过不等于百炼可用。 |
| ② 单库功能联调 | 用合成或脱敏样本打通一次真实上传、导入、检索、组合过滤、PDF 原页跳转和删除。包括：只输入「补考」、不含原词的中文问法、仅存在于 PDF 正文的金额、普通文本附件、无字扫描附件、跨栏目同篇去重、区间边界／未知日及过期版本。登录失效或无 `feed.access` 不能拿到片段。做功能验收，不做供应商对比或性能排名。 |
| ③ 小批真实接入与历史回填 | 先开写入、保持默认读入口不变；小批新旧通知核对阅读页原文、附件原页和检索覆盖数，再分批回填。缺密钥、云端限流、短词样本不命中或证据不符均如实留在未通过清单，不用本地结果代替真实验收。 |
| ④ 上线／撤回 | 增量与回填可对账、关键功能验收通过后切换查询。保留旧读取路径作为整体回滚；关新读入口立即恢复原搜索，索引写入可独立暂停。仅在确认弃用后清理远端资源。发布报告分别记录 CI、实际部署、真实账号验收与存量缺口。 |

**交付边界：** 此 PR 供审查，不合并、不部署、不创建付费云资源。若百炼真实接口无法满足组合筛选或中文短词样例，记录具体失败例并保持读入口关闭。
